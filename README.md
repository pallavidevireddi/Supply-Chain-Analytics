# Supply Chain Analytics Dashboard

## Project Overview
This project focuses on analyzing supply chain operations using SQL and Power BI to generate business insights related to inventory, logistics, manufacturing quality, and supplier performance.

## Tools Used
- SQL Server
- Power BI
- DAX
- Power Query
- Excel

## Dashboard Modules

### 1. Executive Dashboard
- Provides an overall business performance summary
- Tracks total revenue, costs, products sold, and operational KPIs
- Helps management monitor supply chain efficiency

### 2. Inventory Dashboard
- Analyzes stock levels and product availability
- Identifies low-stock products
- Helps improve inventory planning and stock management

### 3. Logistics & Delivery Dashboard
- Tracks shipping costs, transportation modes, and delivery routes
- Identifies high-cost logistics routes
- Analyzes delivery performance and shipping efficiency

### 4. Manufacturing & Quality Dashboard
- Monitors manufacturing costs and production volumes
- Analyzes defect rates and inspection results
- Identifies suppliers with high defect rates

## SQL Analysis Performed
- Revenue analysis
- Supplier performance analysis
- Shipping cost analysis
- Inventory analysis
- Defect rate monitoring
- Transportation and route analysis

## Key Insights
- Identified suppliers with high defect rates
- Found expensive shipping routes impacting operational costs
- Detected low-stock products requiring inventory attention
- Analyzed transportation efficiency and logistics performance
